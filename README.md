# Ертегім

Интерактивная голосовая сказка: ребёнок 3–7 лет отвечает голосом и влияет на сюжет, реплики на казахском с русским подстрочником. Подробнее об идее — [IDEA.md](IDEA.md).

## Структура

| Каталог | Назначение |
|---|---|
| `public/` | детское приложение (статика), деплоится Vercel |
| `api/` | Vercel Edge functions (`transcribe.js`, `classify.js`) |
| `server/` | локальный Bun-сервер: `server.js`, `bins.js` |
| `lib/` | модули без DOM/Bun-зависимостей (blocklist, STT-подсказки, выбор транскрипта, классификатор, Origin-guard) |
| `tools/` | `prerender.py`, `dump-story.js`, `requirements.txt` |
| `tests/` | `bun test` |
| `docs/` | сценарий, статус-отчёты, спеки |

## Быстрый старт

```
cp .env.example .env   # вписать GROQ_API_KEY
bun server/server.js
```

Открыть `http://localhost:3000`. Панель оператора (скрыта от ребёнка) — клавиша `` ` ``,
значок ⚙ в шапке, либо параметр `?op=1` в URL.

Без `GROQ_API_KEY` и/или без ffmpeg/whisper/piper приложение всё ещё работает: живой STT и
live-TTS отключаются, но заранее пре-рендеренные `.wav` в `public/audio/` и ручные кнопки
оператора (✅/🔁/⏭) позволяют пройти историю без микрофона.

## Переменные окружения

Порядок разрешения бинарей: явный env → PATH → tools/.venv (для `PIPER_BIN` — сначала
`tools/.venv`, затем PATH) (см. `server/bins.js`).

| Переменная | По умолчанию | Если не задана/не найдена |
|---|---|---|
| `GROQ_API_KEY` | — | нет STT (Whisper) и LLM-классификатора ответов |
| `GROQ_STT_MODEL` | `whisper-large-v3` | — |
| `STT_LANGS` | `auto,ru` | — |
| `ALLOWED_ORIGIN_EXTRA` | — | API на Vercel принимает только `*.vercel.app` / localhost; свой домен нужно перечислить здесь через запятую (`ertegim.kz,*.ertegim.kz`), иначе все запросы получат 403 (см. `lib/origin-guard.js`) |
| `GROQ_TIMEOUT_MS` | `8000` локально, `12000` на Vercel | — |
| `PORT` | `3000` | сервер слушает 3000 |
| `FFMPEG_BIN` | `ffmpeg` из PATH, иначе бинарь `imageio-ffmpeg` из `tools/.venv` | нет loudnorm-препроцессинга и pitch-shift для TTS, локальный Whisper недоступен |
| `WHISPER_BIN` | `whisper-cli` из PATH | только Groq STT |
| `WHISPER_MODEL` | `tools/models/ggml-small.bin`, если существует | только Groq STT |
| `PIPER_BIN` | `tools/.venv/bin/piper` (Windows: `tools/.venv/Scripts/piper.exe`), иначе `piper` из PATH | `/api/speak` отвечает 503, клиент переключается на пре-рендеренные `.wav` |
| `PIPER_VOICE_KK` | `tools/voices/kk_KZ-issai-high.onnx`, если существует | как выше |

## Озвучка (пререндер)

```
python3 -m venv tools/.venv
tools/.venv/bin/pip install -r tools/requirements.txt
tools/.venv/bin/python tools/prerender.py
```

Скачает голос Piper в `tools/voices/` и озвучит все реплики истории в `public/audio/`.
`--force` — переозвучить всё заново; `--only id1,id2` — только перечисленные реплики.

## Лаборатория STT

Распознавание идёт в два прохода: один и тот же клип отправляется в Groq Whisper
дважды **параллельно** — по одному вызову на каждый элемент `STT_LANGS`
(по умолчанию `auto,ru`), — а `lib/stt-pick.js` выбирает тот
результат, который лучше отвечает на вопрос узла (счёт, развилка, рифма,
поддержка), отбрасывая галлюцинации Whisper («Субтитры сделал DimaTorzok») и
помечая тихие/неуверенные записи как `lowConfidence` — тогда сказка мягко
переспрашивает, не дёргая LLM.

### Почему `auto,ru` и `whisper-large-v3`

Раньше проходы были `kk,ru` на `whisper-large-v3-turbo`. На живом тесте с
телефона реальные казахские ответы возвращались либо пустыми, либо уверенной
казахоподобной бессмыслицей («үңі ғыңңқ») — turbo с принудительным
`language=kk` заставляет модель «договорить» фонетику низкоресурсного языка
вместо честного низкого confidence. Это известный режим отказа, и он хуже
пустого ответа: галлюцинация выглядит как уверенное распознавание и идёт
дальше по пайплайну.

Поэтому по умолчанию: полная модель `whisper-large-v3` (точнее turbo на
низкоресурсных языках; задержка не критична — TTS/микрофон и так занимают
8-12 с под анимацией «думаю») и `auto` вместо `kk` — язык определяет сам
Whisper, а словарная подсказка (`lib/stt-hints-core.js`) и
`isMostlyCyrillic()` остаются. Каждый вопрос в `story.js` и так принимает
ответ на казахском **или** русском, так что заставлять модель выбирать
более сложный язык незачем.

`STT_LANGS=kk,ru` возвращает прежнее поведение (принудительный казахский),
`STT_LANGS=auto` — один проход. Порядок важен: при равном счёте
`lib/stt-pick.js` выбирает первый в списке.

Цена: два прохода — это **два вызова Groq STT на каждый ответ ребёнка** (вдвое
больше запросов и стоимости, чем при одном проходе); пороги `noSpeechProb 0.6` и
`avgLogprob −1.2` в `lib/stt-pick.js` взяты «на глаз» и не настроены — их и надо
откалибровать прогоном лаборатории на реальных детских записях.

Чтобы настроить это на реальных детских записях, есть локальная страница
(только `bun server/server.js`, на Vercel её нет):

```
GROQ_API_KEY=... bun server/server.js
# открыть http://localhost:3000/lab.html
```

Выбрать записи детей, узел (`q_tracks` / `q_fork` / `q_courage` / `q_echo`), для
счёта — `trackCount`, при необходимости поправить `langs` (подставляется из
`STT_LANGS` сервера — так и сравнивают `kk,ru` против `auto,ru` против `auto`),
вписать ожидаемый ответ напротив каждого файла и нажать «Run turbo» / «Run v3».
Таблица покажет оба транскрипта (с пометкой «запрошено→распознано», чтобы было
видно, что именно определил `auto`), выбранный, score, confidence и совпадение
с ожидаемым; внизу — точность и среднее время на файл для каждой модели.

## Деплой

Vercel zero-config: `public/` как статика, `api/` как Edge functions. В настройках проекта
на Vercel задать переменную `GROQ_API_KEY`. Live TTS (`/api/speak`) на Vercel недоступен —
используются только пре-рендеренные `.wav`. На Vercel также нет ни живого TTS, ни
LLM-классификатора (`/api/classify` есть только у локального сервера) — ответ ребёнка
оценивает локальный классификатор в браузере (`classify-local.js`).

`public/voices.html` — dev-страница для подбора голоса Piper, работает только с локальным
сервером.

## Что проверять на реальном устройстве

- STT и LLM-классификацию живьём (Groq): распознавание и разбор детских ответов.
- Pre-roll (обрезание первого согласного в записи).
- VAD-пороги записи на реальных детях, а не на взрослом голосе: `VAD_START_RMS`
  (0.035) измерен на телефоне **до** появления ограничений
  `noiseSuppression`/`autoGainControl`, их надо перемерить в `/lab.html`.
- `STT_LANGS`: `auto,ru` против `kk,ru` на детских записях — по одному вызову
  Groq на проход, так что сравнение стоит денег.
- Казахские реплики (`q_fork`, `q_courage`, `echo_reveal`, `thanks`) — носителем языка.
