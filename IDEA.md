# Ертегім — идея для Idea Battle (10.09)

Интерактивная сказка, где ребёнок разговаривает с героем голосом и влияет на сюжет — не жмёт кнопку «далее», а реально в нём участвует.

## Проблема

Почти весь детский видеоконтент — пассивный: ребёнок смотрит, не отвечает. Родители всё настороженнее относятся к «мультику на автопилоте», но альтернатив, где экран требует реального ответа ребёнка, а не просто выбора из готовых кнопок, на рынке почти нет.

Существующие «интерактивные» форматы (Netflix-спецвыпуски и т.п.) — это заранее прописанное дерево веток. Кнопки просто выбирают путь по дереву. Никакого настоящего диалога там нет.

## Кому это нужно

Родители детей ~3–7 лет, которые уже ищут «развивающий», а не просто развлекательный контент, и готовы дать ребёнку экран, если он реально что-то тренирует (речь, счёт, внимание), а не просто занимает время.

## Что делает продукт (core loop)

1. Герой (например, лисёнок) задаёт ребёнку вопрос по ходу истории — «сколько ягод ты видишь?», «как думаешь, куда пойти — налево или направо?».
2. Ребёнок отвечает **голосом**, своими словами — не выбором из готовых вариантов.
3. Герой реагирует на то, что реально услышал: ведёт сюжет дальше, если ответ подходит; мягко переспрашивает или упрощает, если ответ неверный/расплывчатый.
4. История развивается по-разному каждый раз — нет двух одинаковых прохождений.
5. Родителю в конце — короткий отчёт: какие слова ребёнок использовал, как быстро реагировал, где были сложности.

## Демо-момент для сцены

Судья/зритель играет роль ребёнка, говорит в микрофон случайную фразу — герой отвечает осмысленно, не по вшитому сценарию, история гнётся под ответ прямо на экране. Коротко (30–60 сек), эмоционально, видно, а не пересказано.

## Архитектура (агентный пайплайн)

```
голос ребёнка
   → распознавание речи (STT)
   → фильтр безопасности (жёстко ограничивает тему/словарь до того, как что-либо пойдёт дальше)
   → агент сюжета (решает: усложнить / упростить / повторить — по возрасту и правильности ответа)
   → генератор реплики героя (отвечает в характере, в рамках словаря нужного возраста)
   → озвучка (TTS) + переключение на нужный анимационный фрагмент
   → (параллельно, тихо) агент метрик — считает не запись, а показатели для отчёта родителю
```

Ключевое отличие от готовых интерактивных мультиков: тут нет предзаписанного дерева веток. Ответ обрабатывается заново каждый раз.

## Как закрываем риски

- Голос ребёнка не хранится — обрабатывается и сразу удаляется; родителю уходит только текстовый отчёт по метрикам, не аудио.
- Никакого свободного чата — герой физически не может выйти за пределы заданного банка тем/словаря. Это архитектурное ограничение (whitelist тем, а не instruction-фильтр поверх свободной модели).
- Сессия сама завершается через N минут финалом истории — встроенный лимит экранного времени.
- Панель родителя закрыта PIN-кодом.

## Почему сейчас

Рынок детского контента почти весь пассивный. Родительская тревога по поводу «экрана без пользы» растёт. Продукт, который явно требует ответа ребёнка и явно объясняет родителю, что именно ребёнок тренирует — попадает точно в этот запрос.

## MVP-разрез (что нужно к 10.09, что откладываем)

**Делаем для демо:**
- Одна короткая история (2–3 развилки) с одним героем.
- Заранее отрисованные/сгенерированные анимационные клипы под каждую ветку (не live-генерация видео).
- STT + LLM с жёстко заданным промптом-рамкой (тема/словарь) + TTS — готовые API, не свои модели.
- Простая логика агента сюжета: классификация ответа ребёнка (верно / неверно / не по теме) → выбор следующего клипа.
- Один экран отчёта родителю с 2–3 метриками (моковые данные для демо, если не успеем считать по-настоящему).

**Осознанно откладываем после баттла:**
- Реальное хранение/защиту данных на инфраструктурном уровне (для демо — просто *не сохраняем* ничего, этого достаточно, чтобы показать принцип).
- Библиотеку историй (для демо хватит одной).
- Мультиязычность.
- Реальную модерацию голоса на уровне продакшена — для демо ограничиваемся жёстким промптом + coded whitelist тем.

## Открытые вопросы

- На чём быстрее собрать анимацию клипов за неделю — готовый набор иллюстраций + простая smart-анимация, или статичные картинки с движением камеры?
- STT: браузерный Web Speech API (бесплатно, но качество похуже) или Whisper API (дороже, но надёжнее для детской речи)?
- Нужен ли реальный микрофон на сцене или демо через заранее записанные реплики + live-реакция агента?
