# Ертегім — сценарий демо (Next Steps #1)

Одна история, два героя (лисёнок → совёнок), медведь только на экране выбора персонажа («скоро»). Соответствует Demo Flow из дизайн-документа: Fox всегда первый; correct → хендофф на Owl; blocked → история заканчивается сразу, хендоффа нет; третья попытка (reveal) — герой сам называет ответ и едет дальше, второго переспроса никогда не бывает.

⚠️ Я не носитель казахского — переводы нужно показать носителю до 10.09, особенно рифму совёнка (строка Owl_question) и reveal-реплики.

## Состояния (id для будущей state machine)

```
fox_intro → fox_question
  ├─ (верный ответ)        → fox_correct   → owl_intro
  ├─ (неточный, 1-я попытка) → fox_reask    → fox_question (повтор, упрощённо)
  ├─ (неточный, 2-я попытка) → fox_reveal   → owl_intro
  └─ (BLOCKLIST сработал)   → BLOCKED       → (конец, без owl_intro)

owl_intro → owl_question
  ├─ (верный ответ)          → owl_correct  → ending
  ├─ (неточный, 1-я попытка) → owl_reask    → owl_question (повтор)
  └─ (неточный, 2-я попытка) → owl_reveal   → ending

ending → parent_report (мок-экран)
```

## Лисёнок (fox) — счёт

**fox_intro**
> «Сәлем! Мен — түлкі. Кел, бірге ойнайық!»
> (Привет! Я лисёнок. Давай поиграем вместе!)

**fox_question**
> «Мына бұтада неше жидек бар? Санап көрші!»
> (Сколько ягод на этом кусте? Посчитай!)

**fox_correct** (WoZ нажал «Верно»)
> «Дұрыс! Өте жақсы санадың!»
> (Правильно! Ты отлично посчитал!)

**fox_reask** (WoZ нажал «Переспросить», 1-я попытка)
> «Тағы бір рет қарайықшы. Жидектерді бірінен соң бірін санап көр.»
> (Давай посмотрим ещё раз. Посчитай ягоды по одной.)
> → возврат на fox_question

**fox_reveal** (WoZ нажал «Переспросить» второй раз подряд → авто-раскрытие, per design doc "third strike")
> «Ештеңе етпейді! Бірге санайық: бір, екі, үш! Үш жидек екен!»
> (Не страшно! Давай посчитаем вместе: один, два, три! Три ягоды!)
> → переходит в owl_intro как обычно, БЕЗ повторного переспроса

**BLOCKED** (сработал `spike/blocklist.js` автоматически, скриптованная фраза-триггер)
> Ребёнок/волонтёр говорит: «Маған ойыншық сатып бер»
> Экран: ⛔ «Заблокировано — вне темы» (см. `app/public/index.html`)
> История заканчивается здесь — хендофф на owl НЕ происходит (per Demo Flow resolution).

## Совёнок (owl) — рифмы

**owl_intro** (произносит лисёнок при хендоффе, затем говорит сова)
> Лисёнок: «Тамаша! Енді достым үкінің кезегі!»
> (Отлично! Теперь очередь моего друга совёнка!)
>
> Сова: «Сәлем, мен — үкі. Мен саған сөз айтам, сен соған ұйқас сөз тап!»
> (Привет, я совёнок. Я скажу слово, а ты назови слово, которое на него похоже по звучанию!)

**owl_question**
> «Мысық — деп айттым. Осыған ұйқас сөз тап!»
> (Я сказал «мысық» (кот). Найди слово, похожее по звучанию!)
> ⚠️ проверить с носителем — нужна реально рифмующаяся пара для демо

**owl_correct**
> «Керемет! Тыңдауға өте жағымды болды!»
> (Замечательно! Очень приятно звучало!)
> → ending

**owl_reask** (1-я попытка)
> «Тағы да ойлан. Соңы «-ық» болатын сөз бар ма?»
> (Подумай ещё раз. Есть слово, оканчивающееся на «-ық»?)
> → возврат на owl_question

**owl_reveal** (2-я попытка, авто-раскрытие)
> «Ешбір қиындық жоқ! Мысалы, «қасық» деуге болады!»
> (Ничего страшного! Например, можно сказать «қасық» (ложка)!)
> → ending

## Финал

**ending**
> Лисёнок и совёнок вместе: «Керемет ойын болды! Сау бол!»
> (Отличная была игра! До встречи!)
> → показывается мок-экран отчёта родителю (`app/public` — TODO Next Steps #6)

## Скриптованная фраза-триггер (для теста BLOCKED на сцене)

Ровно эта фраза должна быть произнесена волонтёром намеренно один раз за демо:
> **«Маған ойыншық сатып бер»**

Уже проверена на фаззи-блоклисте (`spike/blocklist.js`) — срабатывает даже при шумной STT-транскрипции («ойынчық», «қызатып», «бір» вместо оригинала).

## Открытые вопросы

- Owl_question нужна реальная рифмующаяся пара на казахском — сейчас черновой вариант, не проверен носителем.
- Нужно решить: reveal-реплики (fox_reveal, owl_reveal) — куда именно ведут после (сейчас: fox_reveal → owl_intro как обычно; owl_reveal → ending как обычно) — соответствует design doc "advances... never a second re-ask", но явно не уточнено, поэтому фиксирую здесь как решение.
