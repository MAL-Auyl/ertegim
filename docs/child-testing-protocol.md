# Протокол тестирования с детьми 3–7 лет

Цель: заменить догадки о детской речи измерениями. Один сеанс — 15–20 минут, один ребёнок, один взрослый-оператор. Достаточно 8–12 детей, чтобы увидеть, где пайплайн реально ломается.

## Что измеряем

| Метрика | Как считаем | Порог «ок» |
|---|---|---|
| Точность STT | доля ответов, где транскрипт содержит ожидаемое слово (число / направление / рифма / любое ободрение) | ≥ 70 % с первой попытки |
| Точность вердикта | доля ответов, где ИИ/локальный классификатор совпал с оценкой оператора на слух | ≥ 85 % |
| Ложные срабатывания VAD | сколько раз запись стартовала без речи ребёнка / не стартовала при речи | ≤ 1 на сеанс каждого типа |
| Обрезка начала | оператор слышит в `#player`, что первый звук ответа отрезан | 0 |
| Время реакции | из отчёта родителю (`avgResponseSec`) | информативно |
| Удержание | дошёл ли ребёнок до `found` без помощи оператора | ≥ 60 % |

## Подготовка (за день)

1. Ноутбук с Windows: `bun server/server.js`, в `.env` — `GROQ_API_KEY`; в таблице бинарников при старте должны быть найдены `ffmpeg` и `piper` (иначе — только `.wav`-озвучка, это тоже допустимо).
2. Внешний микрофон/гарнитура — не встроенный микрофон ноутбука. Уровень записи 70–80 %.
3. Открыть `http://localhost:3000/?op=1` в Chrome, разрешить микрофон, пройти сказку самому один раз.
4. Тихая комната; телефон родителя на беззвучном.
5. Распечатать лист согласия (ниже) и лист наблюдения — по одному на ребёнка.

## Ход сеанса (15–20 мин)

1. **Знакомство (3 мин).** Взрослый показывает лисёнка на экране, не объясняет правил. Единственная инструкция ребёнку: «Лисёнок будет спрашивать — отвечай ему вслух».
2. **Прогон 1 (5–7 мин).** Оператор молчит и не подсказывает. Вмешивается только если сцена стоит > 20 с (нажимает ⏭ Advance) — это фиксируется как «застревание».
3. **Прогон 2 (5 мин).** Сразу повторно (`intro_again`). Наблюдаем, узнаёт ли ребёнок героя, меняется ли поведение на развилке.
4. **Родителю (2 мин).** Показать отчёт после PIN. Спросить: «Что здесь непонятно? Что бы вы хотели видеть?» Записать дословно.
5. Сохранить лог оператора: в панели (`` ` ``) выделить содержимое `#log` и вставить в файл `logs/<дата>-<номер>.txt` (в лог не попадает голос — только транскрипты и вердикты).

## После серии

- Свести таблицу: по каждому вопросу — точность STT и вердикта. Если STT < 70 % на `q_tracks` — сначала крутить `lib/stt-hints-core.js` (подсказку) и пороги VAD в `public/app.js`, потом думать о модели.
- Слова, которые дети реально говорили, но STT не распознал, добавить в `NUM_FORMS` (`public/classify-local.js`) и в подсказки.
- Обновить `docs/status-report-*.md`: «проверено на N детях, точность …».

> Я, ______________________, разрешаю моему ребёнку ______________________ (возраст ___) участвовать в тестировании интерактивной сказки «Ертегім» ____ 2026 г. Мне объяснили, что голос ребёнка обрабатывается для распознавания речи и **не сохраняется**; сохраняются только текст распознанных слов и показатели (время ответа, количество попыток) без имени ребёнка. Я могу прекратить участие в любой момент. Видео/фото не ведётся.
>
> Подпись ____________  Телефон для связи ____________

## Что нельзя

- Подсказывать ответ («скажи три») — ломает измерение.
- Записывать аудио на диктофон/телефон «на всякий случай» — противоречит согласию.
- Тестировать больше двух прогонов подряд — усталость искажает всё.
