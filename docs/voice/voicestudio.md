# Голоса героям через VoiceStudio

Скрипт `tools/prerender_voicestudio.py` озвучивает реплики локальной моделью OmniVoice из приложения
VoiceStudio, и у каждого героя свой голос: лисёнок, сова, медведь. Кто говорит реплику, скрипт берёт
из `public/story.js`, поэтому голоса работают во всех сказках и уроках, включая будущие.

VoiceStudio работает только на вашем компьютере (`http://localhost:3900`), поэтому озвучку запускаете
вы. Отдельное Python-окружение не нужно: хватит Python 3.10+ и Node.js, которые уже стоят для проекта.

## Шаги (Windows, PowerShell, из папки проекта)

1. Откройте VoiceStudio и дождитесь, пока загрузится модель OmniVoice.
2. Обновите проект: `git pull`.
3. Создайте голоса совы и медведя. Голос лисёнка уже есть в `tools\voice-ref\fox_ref_en.wav`.
   ```
   python tools\prerender_voicestudio.py --make-ref
   ```
   Послушайте `tools\voice-ref\owl_ref_en.wav` и `tools\voice-ref\bear_ref_en.wav`. Если голос не
   нравится, пересоздайте его с другим зерном, например `--make-ref owl --force --seed 7`.
4. Озвучьте реплики совы и медведя в пробную папку:
   ```
   python tools\prerender_voicestudio.py --characters owl,bear
   ```
   Скрипт напишет путь к странице `review.html`. Откройте её в браузере: слева новый голос, справа
   то, что сейчас в приложении.
5. Если нравится, запишите в приложение:
   ```
   python tools\prerender_voicestudio.py --characters owl,bear --to-public
   ```
   Скрипт сам обновит список файлов для работы без интернета.
6. Проверьте сказку локально, затем закоммитьте и отправьте:
   ```
   git add public\audio public\offline-manifest.json tools\voice-ref
   git commit -m "Owl and bear voices from VoiceStudio"
   git push
   ```

Чтобы заменить и голос лисёнка, уберите `--characters` или укажите `--characters fox`. У лисёнка
187 реплик из 217, на процессоре без видеокарты это долго. Можно частями, например
`--prefix bh_,q_bh_` для одной сказки.

## Голос через «Режиссёрский ИИ»

В Voice Studio есть «Режиссёрский ИИ»: вы описываете голос обычными словами, а он показывает токены
голоса, инструкцию для синтеза и поправку скорости речи. Это удобный способ подобрать голос каждому
герою.

1. Вставьте в поле «Направление» описание героя. Готовые варианты, на английском, потому что модель
   лучше понимает его:
   - **Лисёнок:** `A cheerful little fox cub, a six-year-old child, bright and playful, warm and kind, speaks clearly and a little slowly for small children.`
   - **Сова:** `A gentle, wise young owl girl, soft and calm, a little shy, a warm bedtime-story voice, speaks slowly and softly.`
   - **Медведь:** `A big, kind, friendly bear, a low warm voice, slow and cozy, never scary, a gentle giant talking to a small child.`
2. Скопируйте токены, которые покажет режиссёр, в поле `instruct` нужного героя в файле
   `tools\voice-ref\voices.json`. Поправку скорости впишите в `speed`: `0.9`, `"0.9x"` или `"-10%"`.
3. Пересоздайте голос героя и озвучьте заново:
   ```
   python tools\prerender_voicestudio.py --make-ref bear --force
   python tools\prerender_voicestudio.py --characters bear
   ```
   Скрипт сам перерисует только реплики этого героя.

Поправка скорости применяется ко всем репликам героя и требует ffmpeg. Без ffmpeg скрипт предупредит
и оставит обычный темп. Сейчас в `voices.json` сова на 5 % и медведь на 10 % медленнее лисёнка: так
их проще отличить на слух.

## Что скрипт делает сам

- **Свой голос каждому герою.** Голос придумывается по описанию на английском предложении, так
  OmniVoice работает стабильнее всего. Казахские реплики клонируются с этого образца.
- **Громкость под Piper.** Каждая реплика выравнивается до −16 dBFS, пики не выше −1 dBFS. Сова не
  будет громче лисёнка, которого озвучил Piper.
- **Медленнее в уроках букв.** Реплики уроков замедляются на 15 %, как у Piper, если на компьютере
  есть ffmpeg.
- **Только изменённое.** Повторный запуск озвучивает заново лишь реплики, у которых поменялся текст,
  герой или голос. Отпечатки лежат в `tools/voice-ref/voicestudio-public-state.json`, его нужно
  коммитить вместе с аудио. Прерванный запуск продолжится с места остановки.
- **Проверка без VoiceStudio.** `--dry-run` показывает, что будет озвучено.

## Как приложение выбирает звук

Сказка сначала играет готовый файл `public/audio/<id>.wav`. Живой синтез Piper на локальном сервере
используется только для реплики без файла. Поэтому голоса VoiceStudio звучат везде: и на сайте, и
на локальном сервере.

## Лицензия

Веса OmniVoice распространяются по CC BY-NC. Их можно использовать для демо, тестов и
некоммерческого пилота, но нельзя в платном продукте. Если Ертегім станет платным, вернитесь к Piper
(`tools/prerender.py`) или к собственному дообученному голосу (`docs/voice/finetune-guide.md`).
