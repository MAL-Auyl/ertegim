# База сказок Ертегім

Каждая сказка после первой («Түлкі інісін іздейді») — это данные в реестре `TALES` в `public/story.js`. Движок, полка на главной, наклейки, отчёт родителю, кабинет логопеда, серверное распознавание и озвучка читают реестр сами, поэтому новая сказка не требует правок кода.

## Как добавить сказку

1. В `public/story.js` опишите узлы сказки по образцу `TALE_BEAR_HONEY`: id с собственным префиксом (`xx_` для реплик, `q_xx_` для вопросов), `kind` (`narration` или `question`), герой (`character`: fox, owl, bear), поза, сцена (`bg`: night, river, forest, cave, dawn, lesson), реплика на казахском и русском.
2. Вопросы — те же режимы, что в уроках: `imitate` (повторить звук или слово, список `accept`), `pick` (две картинки, ответ голосом или пальцем), `open` (любая речь, узел контакта), `exact` + `count` + `overlay: { items, emoji }` (посчитать предметы). У каждого вопроса — `criterion` для ИИ-оценки, `hint` для распознавания и лесенка `onReask` → `onReveal`: провалить сказку нельзя.
3. Добавьте запись в `TALES`: старт, повторный старт, финал, название на двух языках, обложка, тема карточки, текст карточки, наклейка, навыки (иконка, название в отчёте, подпись в кабинете и `area` — область на карте речевых навыков: `sounds`, `words`, `understanding`, `counting`, `dialogue`, `breath`, `letters`) и картинки.
4. Нарисуйте картинки в `public/images/tales/` (плоский SVG 200×200, толстый контур `#14181C`).
5. Выполните по порядку:

```
node tools/tale-forms.js          # ответы и подсказки для сервера
tools/.venv/bin/python tools/prerender.py   # озвучка новых реплик
node tools/offline-manifest.js    # список файлов для работы без интернета
bun test                          # tests/tales.test.js проверит сказку целиком
```

Тест `tests/tales.test.js` проверяет любую сказку одинаково: граф всегда доходит до отчёта, каждая реплика озвучена, каждая картинка нарисована, сервер и браузер одинаково оценивают ответы, отчёт, кабинет и наклейки знают сказку. `tests/skillmap.test.js` проверяет, что у каждого навыка есть область.

⚠️ Казахские реплики написаны не носителем. Перед пилотом их нужно вычитать; таблицы ниже для этого.
