## Что улучшать — по приоритету

### 1. Доказательства (важнее любого кода)
- **Тесты с детьми** по `docs/child-testing-protocol.md`: 8–12 детей, записи через `/lab.html`.
  Результат — три цифры на слайд (точность STT, доля дошедших до финала, время ответа) и 30-секундное видео «ребёнок уговаривает лисёнка».
- По записям подобрать пороги: `NO_SPEECH_MAX`/`LOGPROB_MIN` (`lib/stt-pick.js`), `VAD_*` (`public/app.js`), A/B `whisper-large-v3` против turbo (кнопки в лаборатории).
- Пополнить `NUM_FORMS` и подсказки Whisper словами, которые дети реально говорили.

### 2. Прод и сцена
- **Vercel**: прод до сих пор отдаёт старую сборку. Проверить Settings → Git → Production Branch (если `master` — запушить `master`, он уже равен `design-v2` локально) и Root Directory (должен быть пустым). Затем smoke-тест `/api/transcribe` на проде.
- Три репетиции подряд на сценическом ноутбуке + одна «без Wi-Fi» (пререндер + локальный классификатор + кнопки оператора). Гарнитура, не встроенный микрофон.
- Запасной план: видео полного прогона.

### 3. Язык и голос
- Казахские реплики — носителю: `docs/story-script.md`, особенно `q_fork`, `q_courage`, `echo_reveal`, `thanks`.
- Голос: дообучить Piper на записи актёра (40–60 мин студии, GPU 4–8 ч на Colab/RunPod). Лицензия чистая, инференс на CPU. Облачные/клон-TTS — только если казахский на слух правильный; KittenTTS — нет (только английский).

### 4. Продукт (после питча)
- Настоящий PIN родителя (дизайн готов: соль + SHA-256, локаут, сброс с очисткой истории).
- Вторая сказка как данные: шаблон узлов в `public/story.js` — новая история = новый файл, не код. Кандидат — «Аю мен түстер» (цвета).
- Отчёт родителю: динамика по неделям, экспорт/шаринг.
- Ребёнок, отвечающий поверх вопроса, сейчас не захватывается (микрофон включается после реплики) — рассмотреть «barge-in» с подавлением эха, когда будет реальный микрофон для проверки.
- Гибрид с живым голосовым LLM (GPT-Live) только для одной сцены (пещера) — эксперимент, не основа.

### 5. Техдолг (мелкое, по ходу)
- `?route=` теряет `?op=1`; тексты карточек «с совёнком/с медведем» обещают «другую сказку» — уточнить.
- Regression-тест на glob venv в `bins.js`; `voices.html` вне `public/` (сделано) — аналогично для `lab.html` уже сделано.
- Сцены/эффекты: CSS остался частично в `index.html`; двухслойный оверлей — проверить на реальном экране.
- `.superpowers/` и отчёты агентов — вне git, история решений в `docs/superpowers/`.
