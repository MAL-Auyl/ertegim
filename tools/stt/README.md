# Распознавание речи (STT): замеры и локальный сервер

Лаборатория для выбора и дообучения модели распознавания детских ответов.
Все замеры повторяют продакшен-путь из `server/server.js`: та же ffmpeg-предобработка,
те же подсказки (`lib/stt-hints-core.js`), те же два прохода `auto` + `ru` и тот же выбор
ответа (`lib/stt-pick.js`).

## Итог (2026-09-28)

| | Сейчас (Groq large-v3) | Рекомендация: kk-turbo + turbo (ru) |
|---|---|---|
| Ответы из сказки поняты верно | **65%** | **88%** |
| …казахские ответы | 59% | 97% |
| …русские ответы | 76% | 71% |
| Kk/ru-смешанная речь, WER | 47% | 13% |
| Детская речь, медианный WER | 81% | 33% |

- **kk-turbo** — [`shyngys879/kazakh-whisper-large-v3-turbo`](https://huggingface.co/shyngys879/kazakh-whisper-large-v3-turbo)
  (Apache-2.0, ~1500 ч казахской речи), локально через faster-whisper, fp16 на GPU.
- Казахский fine-tune частично забыл русский, поэтому проход `ru` отдаётся обычному
  `large-v3-turbo` («гибрид»); `stt-pick.js` выбирает, как и раньше.
- Дообучение на детской речи проверено и **не дало выигрыша** (88% → 82%), см. «Дообучение» ниже.

## Наборы для проверки

| Набор | Что это | Размер | Лицензия |
|---|---|---|---|
| `child` | [`galammadin-asr/child-asr-kazakh`](https://huggingface.co/datasets/galammadin-asr/child-asr-kazakh), test, случайная выборка | 300 клипов (Groq — первые 100) | не указана → только внутреннее использование |
| `codeswitch` | [`Tim2190/kazakh-codeswitch-asr`](https://huggingface.co/datasets/Tim2190/kazakh-codeswitch-asr) — живая kk/ru-смешанная речь | 31 клип | CC-BY-4.0 |
| `story` | Ответы на вопросы сказки (счёт, развилка, подбадривание, рифма; kk и ru) 4 синтетическими детскими голосами, чистые и с шумом 10 dB (`make_story_set.py`) | 224 клипа | генерация OmniVoice (CC-BY-NC) — только для тестов |

`story` — синтетика, не настоящие дети: она проверяет словарь сказки и kk/ru-логику,
реальные детские голоса проверяет `child`.

## Все результаты

Ответы из сказки (понял ли `stt-pick.js` ответ так, как задумано):

| Система | Всё | Чисто | Шум | kk | ru |
|---|---|---|---|---|---|
| groq (large-v3, сейчас) | 65% | 65% | 65% | 59% | 76% |
| large-v3 локально | 68% | 68% | 68% | 64% | 75% |
| turbo | 79% | 78% | 80% | 83% | 71% |
| kk-turbo | 83% | 84% | 81% | 91% | 68% |
| kk-turbo + large-v3 (ru) | 87% | 88% | 86% | 93% | 75% |
| **kk-turbo + turbo (ru)** | **88%** | 87% | 88% | **97%** | 71% |

Детская речь (`child`, 100 общих клипов) и смешанная речь (`codeswitch`, 31 клип), проход `auto`:

| Система | child WER | child медиана | child зацикливания | codeswitch WER | codeswitch CER |
|---|---|---|---|---|---|
| groq | 71% | 81% | 1% | 47% | 16% |
| large-v3 | 71% | 89% | 2% | 47% | 18% |
| turbo | 70% | 85% | 3% | 49% | 20% |
| kk-turbo | 52% | 33% | 9% | 13% | 4% |
| kk-turbo +tuned | 46% | 35% | 4% | 12% | 4% |

- Высокий общий WER на `child` в основном даёт зацикливание Whisper на коротких
  клипах («неге неге неге …»). Режим `+tuned` (temperature fallback + VAD) вдвое
  снижает его, но на ответах сказки даёт 70% против 83% — поэтому сервер по умолчанию
  без него (`server.py --tuned` включает).
- Времена в `results/summary.json` снимались при общей загрузке GPU (параллельные
  прогоны и обучение) — для сравнения скорости они не годятся. Отдельно: сквозной
  `/api/transcribe` (ffmpeg + 2 прохода) через локальный сервер — ~1.5 с под нагрузкой.
- У kk-turbo сломано определение языка: на казахской речи проход `auto` часто
  называет язык `bg`/`zh` (текст при этом верный). На выбор ответа не влияет, но в
  логе оператора будет странная метка.

## Дообучение на детской речи

`finetune.py` — LoRA (r=32) поверх kk-turbo на 30 ч `child-asr-kazakh` train, 1 эпоха,
~2.5 ч на RTX A4000. Затем слияние и экспорт в CT2 (`models/kk-turbo-child-ct2`).

**Защита от утечки:** в этом датасете test — случайная выборка, 1692 из 1694 видео
теста есть и в train. Поэтому все видео из нашей проверочной выборки `child` (279
видео) целиком исключены из обучения — иначе модель проверялась бы на уже слышанных
голосах.

Результат — **не помогло, в продакшен не идёт** (модель `kk-turbo-child`, 30 ч, 1246 шагов,
loss 0.74 → 0.27):

| | kk-turbo | kk-turbo-child |
|---|---|---|
| Ответы сказки (сама / гибрид с turbo для ru) | 83% / **88%** | 80% / 82% |
| …счёт (`q_tracks`) | 74% | 66% |
| Детская речь: WER / медиана / CER | 52% / 33% / 35% | 52% / 33% / 46% |
| Зацикливания | 9% | 6% |
| Смешанная речь, WER | 12.7% | 12.3% |

Модель подстроилась под детские YouTube-ролики датасета (длинные фразы, мультфильмы)
и потеряла точность на коротких ответах сказки. Что пробовать дальше, если возвращаться:
записи настоящих ответов детей на вопросы сказки (с согласия родителей) вместо
YouTube-речи; меньший learning rate / меньше шагов; смешивать в обучение исходные
данные kk-turbo, чтобы не забывать.

## Как запустить

```powershell
cd tools\stt
uv venv .venv --python 3.12
uv pip install --python .venv\Scripts\python.exe faster-whisper ctranslate2 nvidia-cublas-cu12 "nvidia-cudnn-cu12>=9,<10" fastapi uvicorn python-multipart jiwer soundfile numpy
# модели: см. «Воспроизведение» ниже
.venv\Scripts\python server.py            # http://127.0.0.1:3910/v1
```

В `.env` приложения: `STT_BASE_URL=http://127.0.0.1:3910/v1`. Без этой переменной
`server.js` работает с Groq, как раньше.

## Воспроизведение замеров

```powershell
# данные и модели (≈ 20 ГБ вместе с train для дообучения)
.venv\Scripts\python -c "from huggingface_hub import snapshot_download as s; s('shyngys879/kazakh-whisper-large-v3-turbo', local_dir='hf/shyngys879__kazakh-whisper-large-v3-turbo'); s('Tim2190/kazakh-codeswitch-asr', repo_type='dataset', local_dir='hf/Tim2190__kazakh-codeswitch-asr'); s('deepdml/faster-whisper-large-v3-turbo-ct2', local_dir='models/turbo-ct2')"
.venv\Scripts\ct2-transformers-converter --model hf/shyngys879__kazakh-whisper-large-v3-turbo --output_dir models/kk-turbo-ct2 --quantization float16 --copy_files tokenizer.json preprocessor_config.json
# data/child: test.jsonl + test_audio.zip (и train* для дообучения) с HF, распаковать в data/child
.venv\Scripts\python make_story_set.py     # нужен запущенный VoiceStudio
.venv\Scripts\python eval.py kk-turbo      # groq | large-v3 | turbo | kk-turbo | name=dir | …+tuned
.venv\Scripts\python report.py --hybrid=kk-turbo/turbo
```

## Деплой: где взять GPU

На CPU модель слишком медленная (грубый замер под нагрузкой: ~11 с на проход), значит
нужен GPU. Vercel GPU не даёт, поэтому STT-сервер живёт отдельно. И `server/server.js`,
и Vercel-функция `api/transcribe.js` читают `STT_BASE_URL` (+ `STT_API_KEY`, если сервер
закрыт токеном) и ходят к нему вместо Groq. Если сервер недоступен, а `GROQ_API_KEY`
задан, оба автоматически откатываются на Groq (проверено: выключенный сервер →
`engine: "groq"`, ответ распознан); локальный `server.js` дальше падает на whisper-cli.

| Вариант | Цена | Плюсы | Минусы |
|---|---|---|---|
| **Modal (`modal_app.py`)** | **$0**: Starter даёт $30/мес кредитов без карты; L4 ≈ $0.80/ч только пока работает | не зависит от этого ПК, в простое ноль | холодный старт 10–20 с после простоя; на день жюри — `STT_WARM=1` (≈ $19 за сутки, в пределах кредитов) |
| Hetzner GEX44 (RTX 4000 SFF Ada, 20 ГБ) | €184/мес + €79 разово | всегда тёплый, предсказуемая цена, хватит на обе модели | платишь и в простое; ЕС → задержка до Казахстана |
| Modal / serverless GPU (L4) | ~$0.80/ч реальной работы | ноль в простое, масштабируется | холодный старт (ребёнок ждёт), держать тёплым — платно |
| Этот компьютер + Cloudflare Tunnel | 0 | для пилотов в садике/демо уже сегодня | зависит от одного ПК и его интернета |
| Groq (как сейчас) | по запросам | без инфраструктуры | свою модель туда не загрузить — остаёмся на 65% |

Рекомендация: бесплатно и без зависимости от одного ПК — Modal (шаги в шапке
`modal_app.py`: аккаунт, секрет с токеном, том с моделями, `modal deploy`). Затем в
Vercel: `STT_BASE_URL=https://<…>.modal.run/v1`, `STT_API_KEY=<тот же токен>`. Откат на
Groq остаётся. Когда пойдут регулярные сессии и холодный старт станет мешать — GEX44.
Перед выставлением сервера наружу задайте `STT_SERVER_TOKEN` на сервере и тот же токен в
`STT_API_KEY` у приложения: без него `server.py` отвечает 401. Без токена сервер годится
только для `127.0.0.1` (при другом `--host` печатает предупреждение).
