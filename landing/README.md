# Caspian Games 2026 — sport.yu.edu.kz

Статический лендинг без сборки: HTML + CSS + немного JS.

```
landing/
├── index.html      # разметка
├── css/style.css   # стили
├── js/app.js       # расписание, площадки, языки (ҚАЗ/РУС/ENG), обратный отсчёт
└── img/            # инфографика и афиши
```

## Деплой

Залить содержимое папки `landing/` в корень сайта `sport.yu.edu.kz`
(nginx/Apache — любой статический хостинг). Сервер и база не нужны.

## Как править

- **Расписание, площадки, время** — массивы `SPORTS`, `VENUES`, `CEREMONIES` в `js/app.js`.
- **Тексты на трёх языках** — объект `I18N` в `js/app.js`.
- **Язык по ссылке:** `?lang=kk`, `?lang=ru`, `?lang=en`.
- **Новая афиша** — положить файл в `img/` и добавить `<a class="gallery__item">` в `index.html`.
