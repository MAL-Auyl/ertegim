# Caspian Games 2026 — sport.yu.edu.kz

Статический лендинг в стиле дизайн-системы Yessenov University (Navy / Accent / Gold,
Inter + JetBrains Mono, Font Awesome 6.4). Без сборки и без сервера.

```
landing/
├── index.html      # разметка
├── css/style.css   # стили
├── js/results.js   # ← РЕЗУЛЬТАТЫ: редактировать только этот файл
├── js/app.js       # расписание, площадки, тексты KZ/RU/EN, дашборд, таймер
└── img/            # инфографика и афиши
```

## Разделы

Hero с таймером → Об Играх (текст анонса, страны, церемонии) → **Дашборд результатов**
(KPI, медальный зачёт по странам/университетам, итоги по видам спорта) → Расписание по дням →
Виды спорта → Площадки (2GIS) → Афиши → CTA → Футер с контактами и соцсетями.

## Как обновлять результаты

Откройте `js/results.js`, заполните `podium` у завершённого вида спорта и поменяйте `updated`.
Формат и пример — в комментарии в начале файла. Медальный зачёт, KPI и статусы
(«Алда / Жүріп жатыр / Аяқталды») пересчитываются автоматически.
После правки залейте файл на сервер (кэш браузера: обновить страницу с Ctrl+F5).

## Деплой

Залить содержимое `landing/` в корень `sport.yu.edu.kz`.
Язык по ссылке: `?lang=kk`, `?lang=ru`, `?lang=en`.
