# Caspian Games News Block (WordPress)

Блок для главного сайта: сначала баннер-заголовок «Каспий ойындары – 2026»,
под ним — последние новости по тегу или из рубрики.

## Установка

1. Плагины → Добавить новый → Загрузить плагин → `caspian-games-news.zip` → Активировать.
2. На нужной странице добавьте блок «Шорткод» и вставьте:

```
[caspian_news]
```

Язык определяется сам (Polylang, WPML или язык сайта), и блок берёт свой тег и тексты:

| Язык | Ярлык (тег, иначе рубрика) | Заголовок |
|------|----------------------------|-----------|
| kk   | `kaspij-ojyndary`          | Каспий ойындары – 2026 |
| ru   | `kaspijskie-igry`          | Каспийские игры – 2026 |
| en   | `caspian-games`            | Caspian Games 2026 |

Принудительно выбрать язык: `[caspian_news lang="ru"]`.

## Параметры

Все параметры необязательные и перекрывают значения по умолчанию для языка:
`lang`, `tag`, `category`, `count` (6), `title`, `subtitle`, `dates`,
`more_text`, `site_url` (пусто — скрыть кнопку), `site_text`.

Пример: `[caspian_news category="novosti" count="3"]`
