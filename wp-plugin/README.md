# Caspian Games News Block (WordPress)

Блок для главного сайта: сначала баннер-заголовок «Каспий ойындары – 2026»,
под ним — последние новости по тегу или из рубрики.

## Установка

1. Плагины → Добавить новый → Загрузить плагин → `caspian-games-news.zip` → Активировать.
2. На нужной странице добавьте блок «Шорткод» и вставьте:

```
[caspian_news tag="slug-тега"]
```

Слаг тега: Записи → Метки → колонка «Ярлык».

## Параметры

| Параметр    | По умолчанию                          | Что делает                          |
|-------------|---------------------------------------|-------------------------------------|
| `tag`       | `caspian-games`                       | слаг тега                           |
| `category`  | —                                     | слаг рубрики (если задан, тег не используется) |
| `count`     | `6`                                   | сколько новостей                    |
| `title`     | `Каспий ойындары – 2026`              | заголовок                           |
| `subtitle`  | `VIII халықаралық студенттік ойындар` | строка над заголовком               |
| `dates`     | `5–9 қазан · Ақтау`                   | строка под заголовком               |
| `more_text` | `Барлық жаңалықтар`                   | кнопка на архив тега/рубрики        |
| `site_url`  | `https://sport.yu.edu.kz`             | кнопка на сайт игр (пусто — скрыть) |
| `site_text` | `Ойындар сайты`                       | текст этой кнопки                   |

Примеры:

```
[caspian_news category="kaspij-ojyndary" count="3"]

[caspian_news tag="caspian-games" title="Каспийские игры – 2026" subtitle="VIII Международные студенческие игры" dates="5–9 октября · Актау" more_text="Все новости" site_text="Сайт игр"]
```
